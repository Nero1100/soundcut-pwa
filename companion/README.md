# 可选的 Windows 网页解析助手

**本地视频和音频无需此助手。** PWA 会在需要时自动准备浏览器转换引擎。

此助手用于 YouTube / B站视频页面。下载助手压缩包后，完整解压，再双击 `启动声段.cmd`。

第一次启动会检查并准备 Node.js 22+、yt-dlp 和 FFmpeg，全部保存在助手目录内。缺少 Node.js 时会从 nodejs.org 下载便携运行文件并校验 SHA-256；其他工具从对应项目的官方 GitHub 发布页下载并校验。无需管理员权限，也不会改系统 PATH。需要联网，首次下载量较大。

准备完成后会自动打开本机页面。也可以在同一台电脑上打开 https://nero1100.github.io/soundcut-pwa/ ，展开网页链接导入，点击“连接电脑解析助手”。浏览器如询问本地网络访问权限，请按你的使用意愿允许。

浏览器无法在没有用户操作的情况下安装或启动本机程序，因此 YouTube / B站第一次使用仍需要下载并运行一次助手；手机要免助手解析平台视频，需要另行部署在线解析服务器。

当前助手面向 64 位 Windows。此版本已检查启动脚本语法及本机依赖检测；尚未在完全没有 Node.js 的另一台实体电脑上验证自动安装流程。

解析受平台访问限制影响，不读取浏览器登录 Cookie，不自动处理登录、会员和验证码。输入上限 80 MB、30 分钟。
