# 声段 / Soundcut

一个可安装的 PWA：提取本地视频音轨、在波形上选择时间段、试听并导出 WAV。

## 在线编辑器

本仓库根目录是静态网页，可以直接发布到 GitHub Pages。发布源选择 `main` 分支、`/ (root)`。

- 本地音频和浏览器可解码的视频可直接在浏览器处理。
- 支持拖动选区、输入起止秒数、循环试听、音量调整和 0.15 秒淡入淡出。
- 可安装到桌面或手机主屏幕；离线缓存编辑器，不保存用户音频。
- 文件大小限制为 80 MB；关闭页面后需要重新导入。

## YouTube / B站和额外视频格式

下载仓库，在 Windows 上安装 Node.js 22+，打开 `companion/启动声段.cmd`。首次启动会从官方项目的 GitHub 发布页下载并校验 yt-dlp 和 FFmpeg，随后仅在 `127.0.0.1:47831` 提供本机转换服务。

在这台电脑上打开 PWA，点击“连接转换服务”。手机无法调用这台电脑的 localhost 服务；手机上的视频页面解析需要另行部署服务器。

当前服务将最长 30 分钟、80 MB 以内的素材提取为 AAC 192 kbps 双声道 44.1 kHz，再交给编辑器。视频平台需要公开可访问；不读取浏览器 Cookie，不处理会员、登录或验证码。网站更新或访问限制可能导致解析失败。

## 验证范围

已验证本地 MP4 音轨提取、裁剪时长、双声道 WAV 编码、淡入淡出端点、浏览器导出及错误范围处理。YouTube / B站尚未完成真实链接的端到端验证。PWA 包含 manifest、图标和 service worker，设备安装体验仍需实机确认。

## 开发

纯 HTML/CSS/JavaScript，无前端构建依赖。`audio.js` 包含 PCM 裁剪和 WAV 编码，`app.js` 管理浏览器编辑交互。`companion/` 为本机转换服务；其中 `dist/` 是本机页面副本，修改前端时需要同步。

第三方项目：https://github.com/yt-dlp/yt-dlp 和 https://github.com/yt-dlp/FFmpeg-Builds 。下载的二进制遵循各自许可证，不包含在此仓库中。
