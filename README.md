# 声段 / Soundcut 2.0

在线使用：https://nero1100.github.io/soundcut-pwa/

一个可安装的 PWA：从本地视频提取声音，边听边打标记，精准裁剪并导出 WAV。

## 精准裁剪

- 播放时间实时显示到毫秒；暂停后保留光标位置。
- 播放时按 **M** 或点击“标记此刻”，声音不会中断。标记可跳转、删除，或直接设为起点/终点。
- 拖动边界靠近标记会自动吸附，并显示高亮与时间提示；支持的设备会有短振动。按住 Alt 可暂时取消吸附。
- 可单独试听开头或结尾 3 秒；“听结尾切点前后”播放原音频的切点前 2 秒及后 1 秒，便于判断是否切掉尾音。短片段自动缩短试听范围。
- 时间输入支持 `12.345`（秒）和 `1:12.345`（分:秒）；输入期间不重写内容，按 Enter 或离开输入框后应用。Esc 恢复原值，无效输入不会改变选区。
- 起止点可用按钮微调 10 ms；Shift + 点击微调 1 ms。波形边界聚焦后也能用方向键 / Shift + 方向键微调。
- 波形可放大至 32×，移动可视范围，或一键定位选区起点和终点。
- 空格播放/暂停，I 将当前时间设为起点，O 设为终点。输入文本时不触发快捷键。
- 循环试听、音量调整和 0.15 秒淡入淡出，导出 WAV。

## 换电脑无需安装：本地视频和音频

直接选择本地文件即可。浏览器支持的音轨直接读取；不支持的格式会自动准备 ffmpeg.wasm 浏览器转换引擎。第一次需下载约 31 MB，之后使用浏览器缓存（缓存可能被浏览器清理）。无需 Node.js、电脑助手或管理员权限，文件不会上传到云端。

文件上限 80 MB。浏览器转换限时 3 分钟；较长或复杂视频可能受设备内存、速度或编解码器支持限制。转换引擎将音轨转为 192 kbps AAC、44.1 kHz 双声道再载入编辑器，这一步有损；WAV 导出不会恢复压缩中丢失的信息。

## YouTube / B站页面

这些平台不能仅靠 GitHub Pages 和浏览器转换引擎解析。需要可选电脑助手或另外部署的在线解析服务器。

Windows 助手下载：https://nero1100.github.io/soundcut-pwa/Soundcut-Helper-Windows.zip

完整解压后，双击 `companion/启动声段.cmd`。首次启动自动检查并准备 Node.js 22+、FFmpeg 和 yt-dlp，保存于助手目录内。下载来自官方源并校验 SHA-256，不改系统 PATH，不需要管理员权限。网页不能未经用户操作静默安装/启动本机程序，所以助手仍需第一次手动启动。

助手只监听本机 `127.0.0.1:47831`，并允许本项目的 GitHub Pages 页面调用。手机无法调用另一台电脑的 localhost 服务。公开视频解析也可能受网站限制或变化影响；不读取登录 Cookie，不处理会员或验证码。助手处理素材上限为 80 MB、30 分钟。

## PWA 与状态

在支持的浏览器菜单中选择安装/添加到主屏幕。新版包含应用外壳离线缓存及单独的转换引擎缓存。更新后刷新页面，确认底部显示“声段 2.0”。未导出的音频与标记只留在当前页面，关闭或刷新前请导出。

## 验证

已验证：

- 逐字输入与提交、分秒解析、无效输入保留原选区。
- 实时播放时钟、播放中打标记、拖动吸附到标记的精确时间。
- 结尾 3 秒试听的起止范围。
- 390 px 手机布局无横向溢出。
- 浏览器原本不能解码的 AVI 自动下载转换引擎并提取音轨，未调用电脑助手。
- 时间格式进位、吸附容差与脱离、放大比例与选区范围的单元测试。
- Windows 自动依赖启动器的脚本语法检查。

尚未在完全没有 Node.js 的另一台实体 Windows 电脑上验证首次依赖安装；尚未用用户实际 YouTube / B站链接验证解析成功率。

运行测试：`node tests/editor-core.test.cjs`。
